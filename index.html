Benvinguts als Projectes

Soc l'Olivia de 4rt d'ESO de l'Institut Pompeu Fabra

Aquesta és una plantilla web amb menú desplegable, icones Font Awesome, mode clar i fosc, i disseny responsiu per mòbil i ordinador utilitzant Bootstrap 5.3.8. Aquest és el punt de partida per editar tot i fer projectes amb el professor Francesc Pérez.

El primer que farem és crear un compte a editor de p5js amb el compte de l'institut.

Crearem un objecte, com per exemple una cara, en l'editor anterior es guardarà automaticament i el trobare sota el meu nom en "my sketches"

Si a l'archiu es diu "cara 1" crearé una carpeta anomenada "cara 1" i dintre copiaré 3 arxius que estan a l'editor de p5js, que s'anomenen index.html, style.css i sketch.js i tindré la cara a la meva web /cara1

Al projecte li direm "projecte cares" i al projecte 1.1 li direm "cara 1"
